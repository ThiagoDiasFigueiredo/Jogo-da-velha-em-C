# DESCRIÇÃO DA ATIVIDADE
A atividade consiste em um jogo da velha modularizado em C. O projeto foi desenvolvido pelos alunos: Thiago Dias de Hugo Suassuna. O projeto tem 3 etapas fundamentais: 1 - A criação de um jogo da velha local, no qual o jogador escolhe se quer X ou O e joga localmente com outra pessoa; 2 - Uma IA que joga contra o jogador localmente seguindo um conjunto de regras específicas para a jogabilidade; 3 - O desenvolvimento do modo online utilizando socket (ainda em desenvolvimento). Separamos esse projeto em 6 partes principais, sendo 5 arquivos .h e um arquivo main.c onde vai rodar os códigos implementados nos arquivos correspondentes.

# TEORIA NECESSÁRIA

Os conceitos fundamentais dessa atividade foram: Lógica de programação, estruturas de condição, estruturas de repetição, matrizes, ordem aleatória(rand), cálculos de posição da jogada.
